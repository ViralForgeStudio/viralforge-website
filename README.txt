
ViralForge Studio — static website

Files:
- index.html
- privacy.html
- terms.html
- style.css

Publishing:
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Enable GitHub Pages from Settings > Pages.
4. Choose Deploy from a branch, select the main branch and root folder.
5. Use the resulting public URL as the TikTok Web/Desktop URL.
6. Use /terms.html and /privacy.html for the corresponding TikTok fields.

Important:
TikTok's current App Review Guidelines require a fully developed official website, with visible active Privacy Policy and Terms links. Before production use, replace the template contact/legal text with the project's real operator information and actual data practices.
